# agent-sdlc

## Input from stakeholders

- Mary in engineering wants a reliable site with a popular stack based on TypeScript, giving agents and staff a dashboard for easy access.
- Susan in product has a set of features about agents and their ailments, therapies, and booking appointments.
- Steve in marketing wants an attractive site that works well with a modern browser.

## Prompt
"Empeze un nuevo proyecto, la estrategia es utilizar spec-driven-development, para esto cree 2 carpetas: specs, donde estan 2 archivos: 1. Mission: Como rol de Product Manager, donde se definieron los requerimientos funcionales. 2. Teck-stack: Como Ingeniero de Software, donde esta las condiciones tecnicas del proyecto, para diferentes roles: Frontend, Backend, Quality, etc. Analizalo, preguntame si alguna definicion no esta clara para reescribirlo."
